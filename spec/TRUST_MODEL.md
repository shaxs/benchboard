# BenchBoard v1 trust model (owner-only)

BenchBoard v1 assumes cooperative benchmark participants operating within their assigned DSH project/workspace. Participants receive only the generated starter application, PRODUCT_PRD.md, visible tests, required fixtures, and ordinary project dependencies/tooling. The benchmark owner retains the hidden evaluator/tests, reference implementation, private scoring internals, seeded-defect answer key, and prior benchmark outputs/private evidence. Participants must not be intentionally given private benchmark material. BenchBoard v1 does not claim adversarial OS-level containment against an agent deliberately inspecting arbitrary host paths. Docker and runtime containment are not readiness gates.

This owner decision supersedes earlier containment assumptions. There is one readiness state, READY_FOR_CALIBRATION. Exact public allowlisting, hidden/reference exclusion, deterministic provision/reset hashes, exclusive active-run protection, evaluator separation and private evidence handling remain required. Participants may use normal DSH project/workspace tools; they receive no owner repository, history or review packet. No OS access-denial claim is made. The fairness reviewer may receive private materials solely to assess this benchmark.

Use the measured orchestration environment for the run's declared execution ceiling. From candidate.5 the ceiling is per-run: each seeded manifest declares timeCeilingMinutes before execution, it is immutable once the official clock starts, and deadlineAt is derived from startedAt plus that value. It is a safety bound, not an expected duration. The cooperative process supervisor requests native process-tree termination and records the actual observed stop time and termination result. DSH-managed workers outside the launched process tree require DSH's normal stop mechanism; detached/external workers are not proven stopped by a command exit. Record any stop failure or overrun as harness behavior and retain actual telemetry. Do not hide these behind another runtime layer.
